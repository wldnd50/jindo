# 수업 진도 관리

기본 시간표, 주별 휴강·수업 변경, 반별 차시와 진도를 기록합니다.

## PC와 휴대폰에서 이어 쓰기

1. [수업 진도 관리](https://wldnd50.github.io/jindo/)를 열고 **설정 → Google로 로그인**을 누릅니다.
2. 이전에 기록하던 기기라면 첫 로그인 때 **이 기기 기록 가져오기**를 선택합니다. 예전 동기화 코드를 저장해 둔 기기에서는 설정의 **이전 동기화 코드의 기록 가져오기**로 당시 서버 기록을 선택할 수도 있습니다.
3. 다른 기기에서 같은 주소를 열고 같은 Google 계정으로 로그인합니다. **동기화 완료**가 표시되면 시간표와 진도를 이어서 사용할 수 있습니다.

로그인 전 기록은 해당 브라우저에 보관됩니다. 로그인한 뒤에는 기기에서 수정한 기록을 연결이 복구되면 계정에 반영합니다. 두 기기에서 동시에 수정해 선택이 필요할 때는 설정에서 사용할 기록을 고를 수 있습니다. 선택 전 **내보내기**로 현재 기기 기록을 백업할 수 있습니다.
