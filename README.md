# 수업 진도 관리

국어 수업(1~7반) 진도를 차시 단위로 기록하는 개인용 웹 앱입니다.

- 기본 시간표 + 주별 예외(휴강/변경)로 유동적인 시간표를 반영합니다.
- 반별로 차시 번호가 자동으로 매겨집니다.
- 모바일/PC 모두에서 사용 가능합니다.
- 데이터는 이 사이트를 여는 브라우저(기기)에 저장됩니다. 여러 기기를 오가며 쓰려면 [설정] 탭의 "내보내기/가져오기"로 백업 파일을 옮겨주세요.

## 사용 방법

`index.html`을 열면 바로 사용할 수 있습니다. GitHub Pages로 배포하면 아래 주소로 접속됩니다.

```
https://<깃허브아이디>.github.io/<저장소이름>/
```
